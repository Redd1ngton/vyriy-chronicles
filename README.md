# Вирій: Вербове прикордоння · v0.2

Українська ізометрична action RPG: **один гравець — один персонаж**. Клієнт на Phaser 3.90 та окремий авторитетний сервер кімнат до 8 гравців. Це вертикальний зріз одного регіону, не готовий масовий MMORPG-сервіс.

## Спробувати

https://vyriy-chronicles.syrupyriver9.chatgpt.site

За цим посиланням публікується **статичний клієнт із локальним режимом**. Публічний сервер кімнат до нього ще не підключений. Кнопка кооперативу чесно показує доступність сервера; вона не імітує синхронізацію.

## Запустити повний клієнт і сервер

Потрібен **Node.js 22.13+ (рекомендовано 24)**. SQLite входить до Node; зовнішня БД, API-ключі й платні служби не потрібні.

```sh
npm ci
npm start
```

Відкрити http://localhost:4173 у двох незалежних вкладках. У першій: вибрати «Кооператив», створити кімнату. У другій: ввести її код, обрати іншого персонажа. Кожна вкладка має окрему сесію. Сервер зберігає кімнати та предмети у `.runtime/world.sqlite` (не комітиться). Якщо відкриваєте через інший домен, задайте `VYRIY_ALLOWED_ORIGINS`; для зовнішнього доступу потрібні HTTPS/WSS і постійний серверний процес.

Змінні: `PORT` (4173), `VYRIY_DATA_DIR` (`.runtime`), `VYRIY_ALLOWED_ORIGINS` (перелік через кому). Це Node-сервер; його не можна розгорнути просто як статичний Cloudflare Pages сайт. Аналіз безкоштовного Cloudflare й подальшої адаптації: [docs/CLOUDFLARE.md](docs/CLOUDFLARE.md).

## Що реалізовано

- Вибір одного героя з 7 класів: мечник, маг, лучник, послушник, коваль, злодій, стрілець із револьвером.
- Нові деталізовані атласи персонажів, ворогів, босів і оточення; окремі пози руху, атаки й касту. Видимі мечі, луки, посохи, кинджали, молот і револьвер.
- Видимі стріли, кулі й магічні снаряди з серверним часом польоту.
- Один регіон: слобода, туманний ліс, катакомби. Дороги, колізії будинків/дерев/води/стін, закриті ґрати, пошук шляху, видимість за дистанцією та перешкодами.
- NPC, крамниця, скрині, вогнища, пастки, печатки, секрети, важіль, вівтар, сюжетне завершення.
- Отрута, прокляття, лікування, щити, захист, підсилення, сповільнення, корені, оглушення, ухилення та вампіризм.
- 9 різних типів ворогів; боси з власними силуетами, телеграфами, другою фазою й захисною печаткою Хранителя.
- Кап 85, +5 очок за рівень, спеціалізації 20/40/60, фінальна пасивна форма 85. Спеціалізації змінюють прийоми, а не тільки числа.
- Предмети з унікальними ID/власником, вимогами, характеристиками, описами та реальним порівнянням при заміні.
- Серверні кімнати, готовність, лідер, голосування, спільний перехід, перепідключення, персональний лут, двостороння передача предметів, ідемпотентність ресурсних запитів.
- Збереження v2; міграція прогресу v1 без видалення оригіналу, експорт/імпорт тільки локального режиму.

## Керування

ПК: **WASD / стрілки** або клік по землі; **Пробіл** — атака; **1/2** — навички; **3** — зілля; **E** — взаємодія.

Телефон: дотик по землі або екранний джойстик, дотик до ворога, великі контекстні кнопки внизу. Наведення не потрібне. У вікні 390×844 компонування перевірено; фізичний iPhone/Android не тестувався.

Поговоріть із Орисею, заберіть стартову скриню. Північна стежка веде до лісу. Зберіть 3 печатки, поверніться до храму. У катакомбах знайдіть важіль, розбийте захисну печатку та здолайте Хранителя; скриня й вівтар завершують розділ.

## Перевірки

```sh
npm run check
npm test
```

Мережевий інтеграційний тест запускає окремий процес сервера та реальні незалежні WebSocket-з’єднання. Перевіряє спільний бій, голосування й перехід, інвентар і передачі, повторні команди, відновлення сесії та ліміт 8 гравців. Це функціональна перевірка, не навантажувальний тест масового MMO.

## Оновлення 0.3

- 8 сполучених зон: слобода, ліс, катакомби, Росисті луки (1–5), Болотяні святині (14–28), Собор (28–42), Попелясті землі (42–62), Перевал (62–85). Нові зони використовують наявні атласи; це розширення маршрутів, подій та розстановки, без заяви про нові види спрайтів.
- Пасивні сімейства: росинки, гриби, дракони та лісові вартові. Решта агресивні; переслідування обмежене територією. Слабші спавни групові, сильніші поодинокі.
- 18 NPC-завдань із серверною перевіркою умов, одноразовою нагородою, особистими сюжетними предметами та розгалуженнями діалогу.
- 4 навички кожного класу, ранг 1–5, 2 змінювані швидкі комірки. Початкові навички відкриті; інші на 8/16 рівнях. Кожен ранг після першого вимагає ще 2 рівні. Кожен рівень дає 1 очко навичок.
- Інвентар із вкладками та групуванням витратних предметів. 28 професійних сетів (84 предмети) на 10/26/46/68 рівнях: незвичайні, рідкісні, епічні, легендарні. Бонуси за 2/3 частини враховані в реальному порівнянні. Базові предмети звичайні.
- Досвід рівня: `120 + 30L + floor(24L² + 1.6L³)`. Нагорода монстра: `(22 + 12M) × коефіцієнт різниці рівнів` (бос ×2). При перевазі гравця 3/5/7/10 рівнів коефіцієнт 0.6/0.25/0.1/0. За сильнішого ворога +2.5% за рівень, максимум +20%. Точний час прокачування потребує тривалих ігрових сесій; формули не є обіцянкою конкретного часу.
- Поради характеристик для кожної професії з явним добровільним розподілом до 5 вільних очок.
- Збереження v3 мігрує v2, зберігає героя, рівень, предмети та виконані події. Населення поточної зони один раз оновлюється для нового контенту. Ключ браузерного сховища збережено для сумісності. Статична публікація залишається локальною; авторитетний Node-сервер запускається окремо.
