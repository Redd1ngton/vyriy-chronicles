## Економіка 0.4

Продаж прямо з інвентаря: матеріали, зілля, карти та неспоряджені речі; одиницями або цілим стеком. Споряджені, особисті, квестові й зарезервовані для передачі речі захищені. Обладунок, зброя та витратні речі продаються за 25% ціни; матеріали зберігають базову вартість.

«Відлуння душ»: 3% шанс за відповідного рівню звичайного ворога, 3 + floor(рівень/20) за боса, 1 + floor(рівень/20) за квест. За ворога без XP відлуння не даються. У торговця одне відлуння коштує 2500 Z, без класової знижки.

Для кожної вивченої навички: до 5 рангів критичного шансу (+2 в.п. за ранг; лише шкода/лікування) і до 5 рангів короткого класового післясвітіння. Підсилення відкриваються з 10 рівня; наступні ранги — через 5 рівнів. Післясвітіння виникає після завершення касту; перерваний каст його не дає. Дані зберігаються разом із героєм.

# Вирій: Вербове прикордоння · v0.2

Українська ізометрична action RPG: **один гравець — один персонаж**. Клієнт на Phaser 3.90 та окремий авторитетний сервер кімнат до 8 гравців. Це вертикальний зріз одного регіону, не готовий масовий MMORPG-сервіс.

## Спробувати

https://vyriy-chronicles.syrupyriver9.chatgpt.site

За цим посиланням публікується **статичний клієнт із локальним режимом**. Публічний сервер кімнат до нього ще не підключений. Кнопка кооперативу чесно показує доступність сервера; вона не імітує синхронізацію.

## Запустити повний клієнт і сервер

Потрібен **Node.js 22.13+ (рекомендовано 24)**. SQLite входить до Node; зовнішня БД, API-ключі й платні служби не потрібні.

```sh
npm ci
npm start
```

Відкрити http://localhost:4173 у двох незалежних вкладках. У першій: вибрати «Кооператив», створити кімнату. У другій: ввести її код, обрати іншого персонажа. Кожна вкладка має окрему сесію. Сервер зберігає кімнати та предмети у `.runtime/world.sqlite` (не комітиться). Якщо відкриваєте через інший домен, задайте `VYRIY_ALLOWED_ORIGINS`; для зовнішнього доступу потрібні HTTPS/WSS і постійний серверний процес.

Змінні: `PORT` (4173), `VYRIY_DATA_DIR` (`.runtime`), `VYRIY_ALLOWED_ORIGINS` (перелік через кому). Це Node-сервер; його не можна розгорнути просто як статичний Cloudflare Pages сайт. Аналіз безкоштовного Cloudflare й подальшої адаптації: [docs/CLOUDFLARE.md](docs/CLOUDFLARE.md).

## Виправлення 0.3.1 — Cloudflare Workers

Репозиторій тепер містить `wrangler.jsonc`: Worker `worker/index.js` обслуговує статичну гру з `dist/`. У Workers Builds: **Build command** `npm run build`, **Deploy command** `npx wrangler deploy`, **Root directory** — корінь репозиторію. Не запускайте `npm start` у Workers: це окремий Node-сервер кооперативу.

Для Pages (інший продукт): build `npm run build`, output `dist`; для вашої адреси workers.dev використовуйте Workers-конфігурацію вище.

Завантажувач показує прогрес графіки та помилки, відновлення недоступної мережевої сесії обмежено 4 секундами. JS-модулі мають єдину версію URL, щоб уникнути змішування старого й нового коду з кешу. Збереження не очищаються. На телефоні джойстик праворуч, атака 88 px ліворуч, дві навички дугою над нею, зілля збоку, взаємодія над джойстиком. У горизонтальному режимі бойові дії також залишаються ліворуч.

Елітні модифікатори: панцирний (броня), отруйний (отрута), несамовитий (швидкість, сила та позначений удар). Підвищені HP, 1.6× EXP, жар-уламок та відлуння лише для відповідних рівню ворогів.

Ковадла у Вербовій слободі та підземеллі замку II. Зніміть річ: розбір безповоротно перетворює її на матеріали (має окреме підтвердження); гартування гарантоване до +5, +12% базових показників за ранг. Легендарні нагороди можна гартувати, але не розбирати. Передані у пропозиції предмети заблоковано.
