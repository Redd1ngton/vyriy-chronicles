# Вирій: Хроніки Оберегу

Мобільна українська соло Web RPG, натхненна Ragnarok Online. Готовий до запуску ігровий прототип; не MMO.

## Запуск

Потрібен тільки статичний HTTP-сервер:

```sh
python3 -m http.server 8080 --directory dist
```

Відкрийте http://localhost:8080. Не відкривайте index.html через file://: ES-модулі потребують HTTP.

Для Cloudflare Pages: build command порожній, output directory `dist`. Серверні залежності та змінні середовища не потрібні.

## Гра

Торкніться істоти для бою, землі — для руху. Увімкніть автобій, оберіть лідера серед 6 героїв. Виконуйте сюжетні завдання, забирайте нагороди, відкривайте регіони. На Job 10 оберіть професію в меню «Шлях». Підвищуйте характеристики в «Загін»; купуйте спорядження в «Торг», одягайте в «Речі». Вогнище лікує загін. Клавіші 1–4 дублюють панель дій.

40 істот, 5 регіонів, Base/Job прогрес, карти, здобич, інвентар, щоденне доручення, локальний AFK, JSON-експорт/імпорт збережень. Усі дані зберігаються лише у поточному браузері; очищення даних сайту видаляє їх. Скористайтеся експортом у налаштуваннях.

Повна специфікація, формули, wireframe та відмінності MVP від запланованої гри: [docs/ARCHITECTURE_UK.md](docs/ARCHITECTURE_UK.md). Серверна PostgreSQL схема: [docs/schema.sql](docs/schema.sql).

## Перевірка

Node.js 20+; залежностей немає.

```sh
npm test
npm run check
```

## Межі версії

Це соло-прототип із процедурними піксельними спрайтами/портретами. Немає серверного мультиплеєра, P2P ринку, гільдій та фінальних мальованих аніме-портретів. Моделі деяких спеціальних властивостей монстрів та розширені бойові правила описані як наступний етап, а не реалізовані можливості. Усі формули авторські, не точна емуляція RO.

## Структура

`dist/` — весь вебклієнт; `docs/` — специфікація і DDL; `tests/` — автоматичні перевірки; `.github/workflows/ci.yml` — CI без зовнішніх залежностей проєкту.
